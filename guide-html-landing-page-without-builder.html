How to make a landing page without a website builder

You don't need a monthly page-builder subscription for one good page. Plain HTML, a free host and a clear structure will get you live this afternoon.

What a landing page needs, in order

  1. Headline: the outcome, in plain words. "Plan your week in five minutes" beats "The future of productivity".
  2. One sentence of how: what it is and who it's for.
  3. One action: a single button or email box. Two competing buttons halve your clicks.
  4. Proof: a screenshot, a short demo, or real numbers. Real testimonials only.
  5. Answers to doubts: price, how it works, what happens after signing up.
  6. The same action again at the bottom.

Step by step

  1. Start from a template so the layout and mobile view are already done. Our free waitlist page is one HTML file and one CSS file.
  2. Write your words in a text file first. Headline, one sentence, button label, three short answers. Then paste them in.
  3. Change one colour. Most templates have a single brand colour variable at the top of the CSS.
  4. Connect the form. Services like Formspree or Netlify Forms collect emails from a plain HTML form, without any server code.
  5. Publish free. Drag the folder onto Netlify Drop, or push it to GitHub and turn on GitHub Pages. Cloudflare Pages and Vercel work too.
  6. Check it on your phone. Most visitors will see it there first.

Common mistakes

  • A headline about you instead of about the visitor.
  • Too many links in the menu, all leading away from the one action you want.
  • A slow, heavy hero video on mobile.
  • Placeholder text left in. Search the page for "Lorem" before you publish.
