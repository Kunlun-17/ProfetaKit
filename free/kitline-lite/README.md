# Kitline Lite: free HTML & CSS components

A small, framework-free CSS file with **buttons, badges, alerts, cards and form inputs**. No build step, no JavaScript, no dependencies.

```html
<link rel="stylesheet" href="kitline-lite.css">
<body class="kl">
  <button class="kl-btn">Primary</button>
  <span class="kl-badge kl-badge-success kl-badge-dot">Paid</span>
</body>
```

Open `index.html` to see every component. Change the brand colour by editing `--kl-primary` at the top of the CSS.
