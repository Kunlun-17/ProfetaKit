# Free waitlist landing page (HTML)

A clean "coming soon" page with an email signup, ready to publish on GitHub Pages, Netlify, Vercel or any host. One HTML file plus a small CSS file. Works on phones.

**To use it:** change the name, headline and text in `index.html`, change the colour (`--kl-primary` in `kitline-lite.css`), and point the form at Formspree, Netlify Forms or your email tool.
